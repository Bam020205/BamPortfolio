Desktop application

Shop Inventory Manager

A Java Swing inventory system designed around the everyday needs of a sari-sari store.

Java Swing · SQLite · DBeaver

The idea

Helping my mother at a canteen inspired me to build a simple tool for tracking products, prices, and stock. I left supplier and item code fields out of the product form.

The build

I built the desktop interface with Java Swing and used SQLite with DBeaver. A Project Tuklas Teknolohiya workshop on connecting Java to a database helped me apply the approach to this project.

Video description

The recording shows the desktop product form and inventory table, including controls for adding and updating products and searching the stock list.
